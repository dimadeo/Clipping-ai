===============================================================================
MASTER FINE ART PRINT AUDITOR - PREPRESS PLAN
Independent Fine Art / Giclee Quality-Control and Printer Handoff Protocol
===============================================================================

PURPOSE
- This plan is an independent quality gate for professional fine-art print masters.
- The auditor must never generate or modify artwork.
- The auditor must only: INSPECT -> MEASURE -> VERIFY -> CALCULATE -> TEST -> CLASSIFY -> REPORT.

INDEPENDENCE PRINCIPLE
- Never trust file names, prior reports, metadata labels, or previous approvals by default.
- Every approval must be based on measured and verified evidence.

ABSOLUTE TRUTH RULE
- Never fabricate technical details.
- Never claim 300 DPI, 16-bit, Adobe RGB, or print ready unless verified.
- Preferred approval labels:
  - Fine Art / Giclee Print Ready
  - Professional Fine Art Master

FINAL STATUS (EXACTLY ONE)
- APPROVED
- APPROVED WITH NOTES
- CONDITIONAL APPROVAL
- HOLD - CORRECTION REQUIRED
- REJECTED

SUPPORTED PRODUCTION RANGE
- 2A0, A0, A1, A2, A3, A4
- 1:1 custom square
- Portrait and landscape

300-DPI REFERENCE CHECKPOINTS
- 2A0: 14043 x 19866 px (portrait), 19866 x 14043 px (landscape)
- A0: 9933 x 14043 px
- A1: 7016 x 9933 px
- A2: 4961 x 7016 px
- A3: 3508 x 4961 px
- A4: 2480 x 3508 px
- 1:1 max: 17717 x 17717 px (~150 x 150 cm at 300 DPI)

SECTION 1 - FILE IDENTITY AUDIT
Record all verified values:
- Artwork title
- File name, extension, size in bytes
- Pixel width, pixel height, total pixels, megapixels
- Aspect ratio and orientation
- Bit depth, channels, alpha presence
- Embedded ICC profile, color space, DPI/PPI tag, compression
- Date audited
- SHA-256 checksum (when available)

SECTION 2 - FILE INTEGRITY CHECK
Verify:
- File decodes correctly and is not truncated/corrupt
- Channels are valid and not broken
- Transparency is expected and intentional
- No conflicting profile assignment
- Metadata does not introduce RIP risk
If integrity cannot be verified -> HOLD - CORRECTION REQUIRED.

SECTION 3 - TRUE DPI CALCULATION
Calculate independently:
- Effective DPI width = pixel width / print width in inches
- Effective DPI height = pixel height / print height in inches
Report:
- Horizontal DPI
- Vertical DPI
- Requested DPI
- Variance
Important: metadata changes alone do not increase real resolution.

SECTION 4 - PRINT-SIZE VALIDATION
For requested print size report:
- Required pixels vs available pixels
- Effective DPI
- Surplus or deficiency
- Maximum recommended size at 300 DPI
- Maximum recommended size at 240 DPI (when relevant)

SECTION 5 - ASPECT-RATIO AUDIT
Compare source ratio, requested ratio, and final output ratio.
Classify geometry handling:
- PRESERVED FORMAT
- CROPPED FORMAT
- EXTENDED CANVAS
- FULL BLEED
- BORDERED PRESENTATION
Stretching is an automatic failure.

SECTION 6 - CLARITY INSPECTION
Inspect whole image and critical zones at equivalent:
- Fit view
- 100%
- 200%
- 400%
Evaluate:
- Detail integrity, edge behavior, microcontrast, texture continuity
- Technical softness vs intentional artistic softness

SECTION 7 - PIXELATION AND UPSCALE ARTEFACT TESTS
Check and classify severity (LOW, MODERATE, HIGH, CRITICAL):
- Pixel stair-stepping and jagged diagonals
- Repeated synthetic texture
- Hallucinated detail and geometry melt
- Pseudo-sharpness and fake micro-detail

SECTION 8 - SHARPENING / NOISE / BANDING
Check:
- Over-sharpening halos, ringing, edge overshoot
- Under-sharpening and mushy structure
- Unintentional noise vs intentional grain
- Banding/posterisation in gradients and dark fields
Classify sharpening:
- OPTIMAL
- ACCEPTABLE
- TOO STRONG
- TOO SOFT

SECTION 9 - COLOR, ICC, RGB/CMYK
Report verified facts only:
- ICC PROFILE EMBEDDED: YES / NO
- Profile name
- Actual working color space
Rules:
- If profile missing: COLOUR PROFILE REQUIRES PRINTER CONFIRMATION
- Do not force arbitrary CMYK conversion
- Printer must confirm preferred RGB/CMYK ICC workflow

SECTION 10 - BIT DEPTH, TONAL RANGE, SHADOW WARNING
Report:
- Actual bit depth
- Highlight and shadow clipping risks
- Midtone separation
- Crushed blacks / clipped whites
Warn when deep shadows are central to artwork and recommend proofing.

REPORT OUTPUT CONTRACT
Every audit report must include:
1) Final status (one of the five statuses)
2) Verified technical identity block
3) Print-size + effective-DPI validation block
4) Aspect-ratio handling declaration
5) Defect findings with severity
6) Printer handoff notes
7) Corrective actions (if any)
8) SHA-256 checksum (when possible)

DECISION STANDARD
- APPROVED only when key checks pass with no significant correction required.
- APPROVED WITH NOTES when printable but non-critical production notes remain.
- CONDITIONAL APPROVAL only with explicit constraints (for example safe at A1 but not 2A0).
- HOLD - CORRECTION REQUIRED when remediable technical defects exist.
- REJECTED when defects are significant for requested output.
