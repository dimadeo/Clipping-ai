Local server only

Shows the whole print job from draft to finished PDFs when this page is opened through run_auditor.ps1 on the computer that runs the pipeline.

    Ink coverage is simulated with a heavy-GCR separation model that approximates a FOGRA39-type conversion from sRGB. Treat TAC figures as a screening estimate and confirm with the shop's output profile. PDF deliveries written by upscale_pipeline.py (one page, one lossless image) are read directly; other PDFs, AI and PSD files are not, so export a flattened proof at final size. Nothing is uploaded unless you run the expert review. The batch monitor reads the batch_status.json that upscale_pipeline.py 1.4 rewrites after every image; its print-quality column is the pipeline's own re-check of each delivered file, with the same ink, black-floor and banding measures as this page (the pipeline ignores plateaus under 6 px, so its banding score runs a little stricter).
