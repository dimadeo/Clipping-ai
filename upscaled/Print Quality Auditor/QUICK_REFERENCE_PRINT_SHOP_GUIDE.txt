GLOSSARY (For print shop discussions)
================================================================================

PPI (Pixels Per Inch)
  → Measure of image resolution. At 100 cm print size, need ~150 PPI for crisp output.

CMYK (Cyan, Magenta, Yellow, Black)
  → Print-native color space for offset lithography. RGB must convert to CMYK.

sRGB / Adobe RGB
  → Print color spaces for digital wide-format (inkjet). RGB stays RGB but tagged.

ICC Profile
  → Color conversion instructions. Embedded profile tells RIP (print processor)
    how to render colors accurately.

Offset Lithography
  → Traditional plate-based printing (like newspaper/magazine). Requires CMYK.

Digital Wide-Format (Inkjet)
  → Large-format inkjet printing (banners, posters). Can accept RGB or CMYK.

TAC (Total Area Coverage)
  → Sum of CMYK ink percentages. Max 300% for offset litho (else muddy/wet).

Rich Black / Process Black
  → Rich black = CMYK mix (e.g., K100 + C40). Process black = K100 only.
  → Use rich black for deeper shadows; process black for neutral grays.

RIP (Raster Image Processor)
  → Software that converts your file to printer commands. Handles anti-aliasing,
    color conversion, resolution adjustment.
