# Glossary

| Term | Meaning in this system |
| --- | --- |
| Agent | A component with a defined task. It may use AI or ordinary rules. |
| API | A way for your application to communicate with another service. |
| API key | A private credential used to access that service. |
| Approval | Your recorded decision to proceed with a specific direction, artwork or price. |
| Aspect ratio | Image shape expressed as width:height. 1:1 is square; 3:2 is landscape. |
| Autopilot | The local prompt-planning feature. It does not mean every production step is fully automatic. |
| Batch | Several image requests created from one approved direction. |
| BFL | Black Forest Labs, the provider used by the FLUX connector. |
| Canvas | The dashboard workspace containing connected movable panels. |
| Collection | A named group of related artworks. |
| Creative brief | Your description of what to create and how it should feel. |
| Creative direction | One possible visual approach to the brief. |
| Crop | Removing part of an image to fit a different shape. |
| Digital download | The file a customer receives, rather than a physical print. |
| DPI / PPI | DPI refers to printer dots; PPI refers to image pixels per printed inch. The dashboard's 300 DPI delivery labels describe 300 PPI image targets. |
| Executor | The service or component that performs creation. |
| FLUX | The image-generation model family used by the BFL service. |
| Handoff | Passing a prompt or result between steps; Midjourney's current handoff needs you to do it manually. |
| HD / UHD / 8K | Resolution labels often used for screens. For artwork, check exact pixel dimensions and the intended print size rather than relying on a label alone. |
| Image count | Number of images requested in the FLUX batch, not the number of prompt candidates. |
| LangChain | Software used to connect the optional Art Director to a language model. |
| LangGraph | Software coordinating the creative workflow stages. |
| LangSmith | A service for tracing and evaluating supported AI workflow runs. |
| Megapixel / MP | One million pixels. A larger number alone does not guarantee better detail. |
| Mockup | A presentation showing artwork in a room or on a product; not necessarily the customer print file. |
| Model | An AI system used to generate text, images or other outputs. |
| Node | One panel or stage in the visual workspace. |
| Pipeline | The sequence of stages from brief to delivery. |
| Pixel | One tiny unit of a digital image. Width × height tells you the pixel dimensions. |
| Polling | The system repeatedly checking whether a provider job has finished. |
| Preview | An image displayed for inspection; it does not certify print readiness. |
| Print-ready | A final file prepared and checked for a particular print size and output process. |
| Product fields | Information such as title, description, price, SKU and tags. |
| Prompt | Instructions sent to a creation model. |
| Publication | Making a product available through the intended Shopify sales channel. |
| Resolution score | A calculation comparing available pixels with the dashboard's 30 × 40 cm, 300 PPI target. Not an artistic assessment. |
| SEO | Search-engine information such as a product page's title and description. |
| SKU | An identifier used to distinguish a product or variant. |
| Texture | The visible suggestion of paint, paper, canvas or another surface. |
| Trace | A record of steps in a supported workflow run. |
| Upscaling | Enlarging an image, sometimes using AI to reconstruct detail. Results still need inspection. |
| Variant | A product option such as a different size or format. Planned sizes are not automatically Shopify variants. |
| Visual score | Your assessment of the artwork's appearance, recorded separately from resolution. |
| Webhook | A message sent automatically from one service to another after an event, such as an order payment. |
